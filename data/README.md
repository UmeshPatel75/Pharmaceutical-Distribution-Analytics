 Data is not published

This analysis uses transaction data from a real pharmaceutical
distribution business. Although the pipeline anonymises customers and
suppliers and scales all monetary values, the underlying data is not
mine to publish and is deliberately excluded.

`../sql/` contains the full extraction and anonymisation pipeline.
